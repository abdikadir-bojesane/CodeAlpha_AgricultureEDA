# Agriculture Exploratory Data Analysis (EDA)

## Project Overview

This project explores agricultural production data from Somalia to identify trends, patterns, and potential data-quality issues. The analysis focuses on crop production, harvested area, and yield across multiple years.

The project was completed as part of the CodeAlpha Data Analytics internship task.

## Objectives

- Explore the structure and quality of the agricultural dataset.
- Analyze crop production trends from 2013 to 2023.
- Compare production across crops.
- Investigate changes in sorghum production over time.
- Identify potential data-quality issues and reporting limitations.

## Dataset Overview

The dataset contains 99 records covering three crops over 11 years (2013–2023).

The indicators include:

- Production
- Area harvested
- Yield

The dataset also contains reporting flags and notes that provide additional context about the reported figures.

## Analysis Performed

- Dataset structure and data-type inspection
- Research-question development
- Crop production comparisons
- Yearly production trend analysis
- Sorghum trend and percentage-change analysis
- Duplicate checks and missing-note assessment
- Review of reporting flags

## Key Findings

- Sorghum has the highest total production among the three crops in the dataset.
- Sorghum production decreased overall between 2013 and 2023.
- Sorghum production fell from 230,776 tonnes in 2013 to 71,000 tonnes in 2023, a decrease of approximately 69.2%.
- The lowest recorded sorghum production was 59,000 tonnes in 2021.
- The dataset contains 41 blank Note fields, which require interpretation in the context of the dataset documentation.
- Reporting flags identify externally sourced, imputed, and estimated figures.

These findings are descriptive and do not establish statistical significance or explain the causes of production changes.

## Tools Used

- Microsoft Excel
- Excel charts and tables
- Exploratory data analysis techniques

## Project Files

The repository contains the Excel workbook used for the exploratory data analysis, including research questions, data quality checks, crop production comparisons, and trend analysis.

## Conclusion

This analysis provides an overview of agricultural production patterns in Somalia and demonstrates how exploratory data analysis can help identify trends and potential data-quality concerns.

Further investigation and additional contextual data would be needed to explain the causes of the observed changes.
